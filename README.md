# naeimi
خودشناسی آگاهی و بیداری

سامانه آموزشی فارسی برای محتوای آگاهی و بیداری معنوی.

## ساختار آموزشی سامانه

ساختار سلسله‌مراتبی محتوای آموزشی:

دوره ← فصل‌ها ← درس‌ها ← رسانه‌ها و ضمیمه‌ها

- هر دوره می‌تواند چندین فصل داشته باشد.
- هر فصل می‌تواند چندین درس داشته باشد.
- هر درس می‌تواند تعداد نامحدودی فایل رسانه‌ای و ضمیمه داشته باشد.
- برای دوره، فصل، درس و هر فایل امکان تعیین عنوان، توضیح و ترتیب نمایش در نظر گرفته شود.
- وضعیت انتشار و سطح دسترسی رایگان/ویژه باید متناسب با نوع محتوا قابل تنظیم باشد.
- فایل‌ها باید امکان جایگزینی و حذف مدیریتی داشته باشند؛ حذف رکورد یا فایل باید با کنترل ارجاعات و مجوزها انجام شود.
- رسانه‌ها باید در کتابخانه رسانه‌ای قابل مدیریت باشند و به بخش مربوط (دوره، فصل یا درس) متصل شوند.

## الزامات توسعه

- پیش از تغییر ساختار دیتابیس، از داده‌ها و روابط موجود محافظت شود.
- دسترسی هنرجو فقط به محتوای منتشرشده و مجاز محدود باشد.
- مدیریت فصل‌ها و رسانه‌ها باید در موبایل نیز ساده و قابل استفاده باشد.
- این معماری برای سایر بخش‌های رسانه‌پذیر سامانه، مانند کتابخانه صوتی، مدیتیشن و مقالات نیز الگوی توسعه خواهد بود.
